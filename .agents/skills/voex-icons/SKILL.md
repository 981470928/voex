# Voex SVG 图标

交付可直接用于本项目的 SVG 源文件。以现有图标的实际轮廓为风格依据，直接绘制矢量路径，不用位图生成后描摹，不把 PNG 包装进 SVG。

## 范围和命名

- 默认只新增 `src/assets/svg/<name>.svg`，名称采用小写 kebab-case；用户给定 `setting` 时使用 `setting.svg`，不擅自改为复数。
- 先检查同名文件和语义相近的图标。已有同义图标时说明其名称；用户明确要求新图标或新变体时绘制新轮廓，不将复制旧文件说成生成。
- 不自动修改组件、sprite 注册逻辑、页面、样式、package.json 或其他图标；遵守用户指定的更窄范围。
- 用户只描述图标含义时选一个清晰、通用的视觉隐喻，直接生成一个方案。只有语义会改变功能含义时再询问。

## 风格依据

以下链接相对于本 skill 目录；其他命令和输出路径相对于项目根目录。生成前按目标选择 2–3 个现有 SVG 阅读并预览，不只参考它们的文件名。

- [gears.svg](../../../src/assets/svg/gears.svg)：圆润齿轮轮廓、实心主体、中心镂空。
- [camera.svg](../../../src/assets/svg/camera.svg)：几何主体、圆角转折、用负空间区分层次。
- [sun.svg](../../../src/assets/svg/sun.svg)：对称布局、圆润端点、约 1.5 单位的细节粗细。
- [book-open.svg](../../../src/assets/svg/book-open.svg)：用闭合填充路径构成较粗的描边外观。
- [clock.svg](../../../src/assets/svg/clock.svg)：实心剪影内的镂空细节。

核心是单色扁平、圆润、紧凑，以 Solid / Glyph 为主，按语义选用 Outline。不要把这套风格统一改成细线图标，也不要强制每个图标同时混用实心和描边。

## 绘制约定

- 根元素使用 `xmlns="http://www.w3.org/2000/svg" width="16" height="16" viewBox="0 0 16 16"`。
- 主体以 `(8, 8)` 为视觉中心，主要轮廓落在 `1..15`，四边约留 1 单位。以光学平衡为准，细长形状可调整占比。
- 常见边缘或内部线条的视觉粗细以 1.5 单位为起点；小圆角以 0.4–0.75 单位为起点，按相邻图标校准，不强制所有曲线同半径。
- 在 16px 下保留必要识别特征。避免不足 1 单位的细碎间隙；简化齿、刻度和分隔线，不能让镂空糊成黑块。
- 单色前景，透明背景。优先省略 `fill` 以继承调用方颜色；项目 [SvgIcon.vue](../../../src/components/SvgIcon.vue) 已使用 `fill: currentColor`。不写固定黑色、白色或品牌色。
- 使用少量闭合 `path`。镂空优先使用复合路径和 `fill-rule="evenodd"`，不要叠白色图形伪造透明洞。描边外观也优先写成填充轮廓，以匹配现有资源。
- 若描边更适合表达目标，明确使用 `fill="none" stroke="currentColor"`，并设置圆端点、圆连接；不要依赖默认黑色描边。
- 不加入渐变、阴影、透明度层次、纹理、3D、文字、背景底板、外部资源或脚本。独立文件使用单个 `svg` 根元素，不输出 `symbol` 集合。
- 坐标默认不超过三位小数；仅在实际渲染需要时增加精度。保留可读的 SVG，不引入图标库或运行时依赖。

## 执行与验收

1. 确认语义、文件名和修改范围，读取参考图标；用一句话确定造型及选择 Solid 或 Outline 的理由。
2. 绘制并写入目标文件。旋转对称形状可用临时代码计算坐标，最终文件只保留 SVG 路径。
3. 解析 XML，检查命名空间、`16×16` 画布、闭合路径、填充规则、无外部引用；检查是否有裁切或破损路径。
4. 在 16、24、32px 实际尺寸预览，并放大检查轮廓。与参考图标同尺寸比较粗细、留白、圆角及视觉重量；用浅底深色、深底浅色验证镂空和颜色继承。
5. 已有预览服务时复用其地址；需要启动时先检查端口，使用 `pnpm preview:svg --port 4175`，通过 `?q=<name>` 定位。只停止本次为验收启动的服务，用户要求关闭的端口不重新占用。截图和临时验收文件放在临时目录，不写入业务目录。
6. 不生成或运行单元测试。这里的“测试生成”指实际生成 SVG、结构检查和视觉验收。不能完成的检查如实注明，不能仅凭源码声称已看过预览。
7. 交付文件链接、预览图及一句简短风格说明。不自动接入 UI，不顺带生成未请求的其他图标。

## 调用示例

```text
$voex-icons 生成 setting 图标
$voex-icons 生成一个 upload 图标，保存到 src/assets/svg/upload.svg
$voex-icons 调整 src/assets/svg/example.svg，使其匹配本项目图标风格
```
